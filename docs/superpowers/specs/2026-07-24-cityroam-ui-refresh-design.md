# 城市漫游前端轻旅行体验升级设计

## 目标

将 `nginx-1.18.0/html/cityroam` 下的全部移动端页面升级为轻盈、现代的旅行与生活方式界面，同时保留现有 Vue 2、Element UI、HTTP 接口、字段和跳转路径。

## 已确认的范围

- 覆盖首页、店铺列表、店铺详情、笔记详情、笔记发布、个人主页、他人主页、资料编辑和两个登录页面。
- 地图与消息入口保留，但因没有对应页面或接口，点击后展示“即将上线”提示，不伪造可用功能。
- 既有业务动作（登录、点赞、关注、发布、资料保存、选店、AI 润色、抢券）保持接口和数据契约不变，并补足可见的加载、禁用、成功和失败反馈。
- 不修改后端、数据库、Nginx 配置、当前日志或 `application.yaml`。

## 视觉系统

使用暖白背景、深蓝正文、海盐蓝主色和珊瑚橙行动色。页面采用大圆角卡片、低对比阴影、柔和渐变和留白来替代当前工具型视觉；所有页面在 390px 宽移动端优先呈现，并在较宽视口保持居中且不拉伸内容。

图标使用少量本地化的 Lucide SVG（返回、关闭、首页、地图、发布、消息、用户、搜索、定位、收藏、点赞、分享、编辑和提示等）。Lucide 的线性 SVG 风格可统一色彩、尺寸和描边，且采用 ISC 许可；将选择的图标文件放入项目而不是运行时访问第三方图床。

## 页面设计

### 全局

- 共享设计令牌定义色彩、字体层级、间距、圆角、阴影、焦点态和 reduced-motion 降级。
- 统一页面顶栏、卡片、主要/次要按钮、输入框、空状态与轻提示。
- 底部导航显示当前页，并为地图、消息提供“即将上线”轻提示；首页、发布和个人中心继续使用原有跳转路径。

### 首页与 AI 向导

- 以城市问候、分类入口和精选笔记构成清晰的信息层级。
- 分类入口、笔记图片和互动区保留原有跳转或请求行为，增加按下态和请求中状态。
- AI 向导在打开、关闭、发送和等待回复时给出可感知状态；现有 AI 请求与上下文传递逻辑不变。

### 店铺页

- 店铺列表使用胶囊排序控件和旅行卡片，突出评分、距离、标签与封面。
- 店铺详情突出封面、地址、营业信息、优惠券与抢购按钮；无库存、未开始、请求中和请求失败均有明确状态。

### 笔记页

- 笔记详情强化作者、内容、互动和评论的阅读层级。
- 发布页的上传、删除、选店和 AI 润色分别提供禁用态、处理中状态与可读错误提示；不改变上传及发布 API。

### 个人与登录页

- 个人页、他人页和资料编辑页统一头像、统计数据、内容流和操作按钮样式。
- 登录页改为清晰的手机号/验证码流程，发送验证码与登录动作维持现有逻辑，并补足按钮状态和错误反馈。

## 实现边界

- 新增一份共享样式表，用于视觉令牌和跨页组件样式；各既有页面样式文件只保存页面特有布局。
- 新增一个小型共享交互脚本，仅负责“即将上线”提示、按钮防重复提交和图片加载失败占位。它不发起新的接口请求，也不保存新数据。
- 页面维持内联 Vue 实例和已有脚本加载顺序；不引入构建系统、npm 依赖或新的 UI 框架。
- 仅在现有页面能够正确加载的前提下替换可见图标；内容图片、店铺分类图片和用户上传图片不被替换。

## 错误处理与可访问性

- 所有新增交互元素使用原生 `button` 或明确的键盘可触发语义，并提供 `aria-label`。
- 请求中按钮不可重复触发；按钮文本或图标表现当前状态。
- 图片加载失败使用本地占位样式，避免破坏卡片高度。
- 尊重 `prefers-reduced-motion`，减少非必要动效。

## 验证

1. 使用 Nginx 启动静态页面，逐页验证 390px 和常规桌面宽度的布局、图片和图标加载。
2. 在浏览器中验证首页分类/笔记跳转、底部导航、点赞、关注、发布、资料保存、登录、优惠券抢购与 AI 向导的加载和反馈状态。
3. 检查浏览器控制台没有新增错误，并确认地图和消息仅显示“即将上线”提示。
4. 运行项目现有 Maven 测试，确认前端静态资源修改没有影响后端测试。

## 非目标

- 不新增地图、消息、搜索、收藏或其他后端能力。
- 不调整 API、数据表、后端 Java 代码、Nginx 配置或用户已有的工作区改动。
